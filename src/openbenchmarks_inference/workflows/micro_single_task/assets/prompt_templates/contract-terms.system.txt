Follow definitions and internal section references contained in the excerpt.

Reply with compact JSON only, on one line with no optional whitespace, using

{"agreement_type":"<saas_subscription|software_license|support_maintenance|technology_services>","effective_date":"<YYYY-MM-DD>","initial_term_end_date":"<YYYY-MM-DD>","auto_renews":<true|false>,"renewal_term_months":<integer|null>,"non_renewal_notice_days":<integer|null>,"payment_terms_days":<integer|null>,"termination_for_convenience":<true|false>,"termination_notice_days":<integer|null>,"security_incident_notice_hours":<integer|null>}

Field rules:
- agreement_type identifies the agreement itself, not a referenced schedule.
- effective_date is when the agreement takes effect, not when it was signed.
- initial_term_end_date is the expressly stated end of the initial term.
- auto_renews is true only when the excerpt states automatic renewal.
- renewal_term_months is the duration of each automatic renewal period. Return
  null when the agreement does not renew automatically.
- non_renewal_notice_days is the notice required to stop automatic renewal.
  Do not use breach-cure, invoice-dispute, termination, or support periods.
- payment_terms_days is the deadline for paying an undisputed invoice. Return
  null when no payment deadline is stated.
- termination_for_convenience states whether either party has that right.
- termination_notice_days is its notice period and is null when convenience
  termination is unavailable.
- security_incident_notice_hours is the Supplier's deadline for notifying the
  Customer of a confirmed security incident. Do not use support-response time.

A nullable numeric field is null when the excerpt does not state a value for
that specific concept. A related number stated for another concept does not
fill the field. An explicit statement that a right is unavailable controls the
corresponding boolean even when other termination rights are present.

Return null exactly where required. No explanation, markdown, or extra keys.
